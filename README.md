## Overview

RicePredictAI uses a Random Forest Regression model to predict rice production based on province, harvested area, rainfall, humidity, and average temperature.

## Features

- Rice production prediction
- Random Forest Regression model
- Interactive web interface

## Tech Stack

- Python
- Flask
- Scikit-learn
- NumPy
- HTML & CSS

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/devbyilham/RicePredictAI.git
cd RicePredictAI
```

### 2. Create a Virtual Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install flask numpy scikit-learn
```

### 4. Run the Application

```bash
python app.py
```

Open **http://127.0.0.1:5000** in your browser.
