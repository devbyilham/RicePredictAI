# RicePredictAI 

**Rice Production Prediction Using Machine Learning**

A machine learning web application to predict rice production using agricultural and environmental data.

## Overview

RicePredictAI uses a Random Forest Regression model to predict rice production based on province, harvested area, rainfall, humidity, and average temperature.

## Tech Stack

- Python
- Flask
- Scikit-learn
- NumPy
- HTML & CSS

## Features

- Rice production prediction
- Machine learning model integration
- Interactive web interface
